## 1. Project Overview
This project demonstrates an end-to-end data analytics workflow using a retail sales dataset. The workflow covers data preparation, exploratory data analysis, visualization, Power BI dashboard planning, and business recommendations.

## 2. Dataset and Preparation
The dataset contains Order ID, Date, Customer ID, Product, Category, Region, Quantity, Unit Price, Discount and Sales.

The raw dataset intentionally demonstrates common data-quality issues: a duplicate order, a missing region, a missing sales value and an invalid negative quantity.

Cleaning steps:
- Remove duplicate records.
- Replace missing Region values with `Unknown`.
- Replace invalid negative Quantity with the median quantity.
- Recalculate missing Sales as Quantity × Unit Price × (1 − Discount).
- Convert Date to datetime.

## 3. Exploratory Data Analysis
The EDA includes dataset structure, descriptive statistics, category performance, regional performance, product performance, monthly sales trends, sales distribution and correlation analysis.

## 4. Data Visualization
The `visualizations` folder contains SVG visualizations for monthly sales trend, sales by category and sales by region. SVG files are lightweight, scalable and display directly in a GitHub repository.

## 5. Power BI Dashboard
Recommended dashboard components:
- Total Sales KPI
- Total Quantity KPI
- Total Orders KPI
- Average Order Value KPI
- Monthly Sales Trend line chart
- Sales by Category column chart
- Sales by Region bar chart
- Product sales table
- Region, Category and Date slicers

Recommended DAX:
```DAX
Total Sales = SUM(retail_sales_clean[Sales])
Total Quantity = SUM(retail_sales_clean[Quantity])
Total Orders = DISTINCTCOUNT(retail_sales_clean[Order_ID])
Average Order Value = DIVIDE([Total Sales],[Total Orders])
```

## 6. Business Insights
- Electronics is a major revenue-driving category in the project analysis.
- Regional performance differs, so region-level targeting can improve sales planning.
- Monthly trends help identify stronger and weaker demand periods.
- Product-level analysis can identify high-value products for inventory and marketing attention.

## 7. Recommendations
1. Prioritize inventory and campaigns for high-revenue categories.
2. Investigate weaker regions and identify products with regional growth potential.
3. Use monthly trends for inventory and promotion planning.
4. Monitor discounts together with sales volume and profitability.
